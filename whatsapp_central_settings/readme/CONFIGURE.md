Acesse **Definições > WhatsApp Central** e preencha cada configuração:

* **Recebimento de ligações — quem deverá receber:** selecione os usuários.
* **Efetuar ligações — quem pode efetuar:** selecione os usuários.
* **Editar templates de mensagem — quem pode editar:** selecione os usuários.
* **Mensagens não atribuídas:** escolha "Ir para a lista de mensagens" ou
  "Atribuir diretamente a um usuário" e, neste último caso, informe o usuário
  padrão.
* **Quem pode ver o menu WhatsApp - Conversas:** selecione os grupos autorizados
  a ver o menu WhatsApp - Conversas no módulo Mensagens (Discuss).

Clique em **Salvar** para armazenar os valores nos parâmetros do sistema.
