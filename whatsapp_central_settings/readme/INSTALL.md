Este módulo está disponível no repositório de addons local
(`/home/rodrigo/odoo18/odoo/extra/social/whatsapp_central_settings`).

1. Atualize a lista de aplicativos no Odoo.
2. Pesquise por **WhatsApp Central Settings** e instale.
3. Acesse **Definições** e localize o bloco **WhatsApp Central**.

É necessário ter os módulos `mail_gateway_whatsapp_messages`,
`mail_gateway_whatsapp` e `mail_gateway` instalados.
