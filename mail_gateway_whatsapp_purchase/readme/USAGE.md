To send a purchase order or request for quotation by WhatsApp:

1. Open a purchase order (in *draft*, *sent* or *confirmed* state).
2. Make sure the vendor has a **phone** or **mobile** number set.
3. Click on **Send by WhatsApp**.
4. Select the WhatsApp gateway and optionally an approved WhatsApp template.
5. Click on **Send**.

The request for quotation PDF is generated and attached to the message
automatically.
