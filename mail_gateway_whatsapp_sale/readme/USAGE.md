To send a sale order by WhatsApp:

1. Open a sale order (in *draft*, *sent* or *confirmed* state).
2. Make sure the customer has a **phone** or **mobile** number set.
3. Click on **Send by WhatsApp**.
4. Select the WhatsApp gateway and optionally an approved WhatsApp template.
5. Click on **Send**.

The quotation PDF is generated and attached to the message automatically.
