Integrate WhatsApp Gateway with Livechat
========================================

This module bridges the ``mail_gateway_whatsapp`` module with ``im_livechat``,
allowing livechat operators to receive and respond to WhatsApp messages
directly from the Odoo Discuss interface.

When a WhatsApp gateway is linked to a livechat channel, incoming WhatsApp
messages automatically create livechat sessions routed to the configured
operators. Operators can then respond through Discuss, and their messages
are sent back via WhatsApp.
